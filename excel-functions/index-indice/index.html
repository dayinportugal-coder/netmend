What INDEX does

Together with MATCH it is the reliable alternative to VLOOKUP, and it works in older Excel that does not have XLOOKUP.

Returns the value (or reference) at a given row and column position in a range.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — INDEX
=INDEX(array, row_num, [column_num])
=INDEX(Prices!C:C,2)

Common mistakes

  • INDEX alone is just “the value in position N”. You almost always pair it with MATCH.
  • A classic exact lookup: =INDEX(Prices!C:C,MATCH(A2,Prices!A:A,0)). The 0 in MATCH is exact match — do not omit it.
  • If you use a two-dimensional array, you must pass both row_num and column_num.
  • INDEX names look similar across languages (INDEX stays INDEX in French and German) — the partner function MATCH does not.

FAQ

What is INDEX in Portuguese?

ÍNDICE. Spanish INDICE, French INDEX, German INDEX, Italian INDICE.

Why use INDEX/MATCH instead of VLOOKUP?

It can look left, it does not break when you insert a column, and you can reuse the MATCH result.

Does it work in older Excel?

Yes. That is why it is still the standard fallback when XLOOKUP is missing.
