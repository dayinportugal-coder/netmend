What TEXTJOIN does

The modern way to build a list, a tag line or an address. Names: UNIRTEXTO, UNIRCADENAS, JOINDRE.TEXTE, TEXTVERKETTEN, TESTO.UNISCI.

Joins a range of text with a delimiter, and can skip empty cells.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — TEXTJOIN
=TEXTJOIN(delimiter, ignore_empty, text1, [text2], …)
=TEXTJOIN(", ",TRUE,A2:A10)
Português (PT) — UNIRTEXTO
=UNIRTEXTO(delimiter; ignore_empty; text1; [text2]; …)
=UNIRTEXTO(", ";VERDADEIRO;A2:A10)
Español — UNIRCADENAS
=UNIRCADENAS(delimiter; ignore_empty; text1; [text2]; …)
=UNIRCADENAS(", ";VERDADERO;A2:A10)
Français — JOINDRE.TEXTE
=JOINDRE.TEXTE(delimiter; ignore_empty; text1; [text2]; …)
=JOINDRE.TEXTE(", ";VRAI;A2:A10)
Deutsch — TEXTVERKETTEN
=TEXTVERKETTEN(delimiter; ignore_empty; text1; [text2]; …)
=TEXTVERKETTEN(", ";WAHR;A2:A10)
Italiano — TESTO.UNISCI
=TESTO.UNISCI(delimiter; ignore_empty; text1; [text2]; …)
=TESTO.UNISCI(", ";VERO;A2:A10)

Common mistakes

  • The second argument is a boolean (TRUE to skip blanks). In Portuguese that is VERDADEIRO, not TRUE — the translator will swap it.
  • Not in very old Excel. CONCATENATE or a helper column is the fallback.
