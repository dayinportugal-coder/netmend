What IFS does

Cleaner than nested IFs for tiers (high / mid / low). The last TRUE (VERDADEIRO, WAHR…) is the catch-all.

Checks several conditions in order and returns the value for the first one that is true.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — IFS
=IFS(logical_test1, value1, [logical_test2, value2], …)
=IFS(C2>=1000,"high",C2>=100,"mid",TRUE,"low")
Português (PT) — SE.S
=SE.S(logical_test1; value1; [logical_test2; value2]; …)
=SE.S(C2>=1000;"high";C2>=100;"mid";VERDADEIRO;"low")
Español — SI.CONJUNTO
=SI.CONJUNTO(logical_test1; value1; [logical_test2; value2]; …)
=SI.CONJUNTO(C2>=1000;"high";C2>=100;"mid";VERDADERO;"low")
Français — SI.CONDITIONS
=SI.CONDITIONS(logical_test1; value1; [logical_test2; value2]; …)
=SI.CONDITIONS(C2>=1000;"high";C2>=100;"mid";VRAI;"low")
Deutsch — WENNS
=WENNS(logical_test1; value1; [logical_test2; value2]; …)
=WENNS(C2>=1000;"high";C2>=100;"mid";WAHR;"low")
Italiano — PIÙ.SE
=PIÙ.SE(logical_test1; value1; [logical_test2; value2]; …)
=PIÙ.SE(C2>=1000;"high";C2>=100;"mid";VERO;"low")

Common mistakes

  • Conditions are tested top to bottom. Put the tightest test first (C2>=1000 before C2>=100) or a mid-tier will never run.
  • If no condition is true and there is no final TRUE, IFS returns #N/A. End with TRUE and a default value.
  • Not in very old Excel. Nested IF is the fallback.

FAQ

What is IFS in Portuguese?

SE.S. Spanish SI.CONJUNTO, French SI.CONDITIONS, German WENNS, Italian PIÙ.SE.

How do I add a default?

Finish with TRUE (or VERDADEIRO / VRAI / WAHR / VERO) and the default value.
