What SUM does

The most-used function, and still worth a language page: SOMA, SUMA, SOMME, SUMME, SOMMA. Also the function hidden inside “just type a total” advice.

Adds numbers, ranges or both.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

=SUM(C2:C100)

Common mistakes

  • SUM ignores text. If a CSV imported amounts as text, the total stays 0. Coerce with VALUE or Text to Columns.
  • A total that includes another total will double-count. Sum the data rows, not a mix of data and subtotals.
