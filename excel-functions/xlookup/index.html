What XLOOKUP does

It replaces most VLOOKUP and INDEX/MATCH work, but the name is still new in other languages (PROCX, BUSCARX, RECHERCHEX, XVERWEIS, CERCA.X).

Looks up a value in one range and returns the matching value from another range, in any direction.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — XLOOKUP
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
=XLOOKUP(A2,Prices!A:A,Prices!C:C,"not found")
Português (PT) — PROCX
=PROCX(lookup_value; lookup_array; return_array; [if_not_found]; [match_mode]; [search_mode])
=PROCX(A2;Prices!A:A;Prices!C:C;"not found")
Español — BUSCARX
=BUSCARX(lookup_value; lookup_array; return_array; [if_not_found]; [match_mode]; [search_mode])
=BUSCARX(A2;Prices!A:A;Prices!C:C;"not found")
Français — RECHERCHEX
=RECHERCHEX(lookup_value; lookup_array; return_array; [if_not_found]; [match_mode]; [search_mode])
=RECHERCHEX(A2;Prices!A:A;Prices!C:C;"not found")
Deutsch — XVERWEIS
=XVERWEIS(lookup_value; lookup_array; return_array; [if_not_found]; [match_mode]; [search_mode])
=XVERWEIS(A2;Prices!A:A;Prices!C:C;"not found")
Italiano — CERCA.X
=CERCA.X(lookup_value; lookup_array; return_array; [if_not_found]; [match_mode]; [search_mode])
=CERCA.X(A2;Prices!A:A;Prices!C:C;"not found")

Common mistakes

  • lookup_array and return_array must be the same size. A mismatch returns #VALUE!.
  • match_mode 0 (or omitted) is exact. Use -1 for exact or next smaller (useful for commission tiers). 1 is exact or next larger. 2 is a wildcard match.
  • If the return array is a whole row or several columns, XLOOKUP spills. When monthly columns are inserted, a hard-coded range such as L:L will not move — look up the header (for example the last heading before “Total”) instead of a fixed column letter.
  • Not available in very old Excel (Excel 2019 and earlier without Microsoft 365). Have a VLOOKUP or INDEX/MATCH fallback if you share the file.

FAQ

What is XLOOKUP in Portuguese?

PROCX. Spanish BUSCARX, French RECHERCHEX, German XVERWEIS, Italian CERCA.X.

How do I return the last two columns before a Total heading?

Do not hard-code column L. Use MATCH or XMATCH on the header row to find “Total”, then return the two columns to its left, or use a table with structured names.

Can it look to the left?

Yes. The lookup array and the return array are separate, unlike VLOOKUP.
