What DATE does

The safe way to write a date in a criterion or a schedule. Names: DATA, FECHA, DATE, DATUM, DATA.

Builds a real date from a year, month and day, so the result does not depend on the regional date order.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — DATE
=DATE(year, month, day)
=DATE(2026,11,12)
Português (PT) — DATA
=DATA(year; month; day)
=DATA(2026;11;12)
Español — FECHA
=FECHA(year; month; day)
=FECHA(2026;11;12)
Français — DATE
=DATE(year; month; day)
=DATE(2026;11;12)
Deutsch — DATUM
=DATUM(year; month; day)
=DATUM(2026;11;12)
Italiano — DATA
=DATA(year; month; day)
=DATA(2026;11;12)

Common mistakes

  • Typing 12/11/2026 into a formula is ambiguous (12 November or 11 December). DATE(2026,11,12) is not.
  • Use DATE inside SUMIFS / COUNTIF criteria: ">="&DATE(2026,1,1).
  • In Portuguese the function is DATA, which is also a common column heading — a sheet named Data plus a function named DATA is confusing but legal.

FAQ

What is DATE in Portuguese?

DATA. Spanish FECHA, French DATE, German DATUM, Italian DATA.

Why use DATE instead of typing the date?

Because 03/09 means March in the US and 3 September in Europe. DATE always means year, month, day in that order.
