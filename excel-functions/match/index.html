What MATCH does

It is the engine behind INDEX/MATCH. People search for it under CORRESP, COINCIDIR, EQUIV, VERGLEICH and CONFRONTA.

Returns the position of a value in a range (the row or column number, not the value itself).

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — MATCH
=MATCH(lookup_value, lookup_array, [match_type])
=MATCH(A2,Prices!A:A,0)
Português (PT) — CORRESP
=CORRESP(lookup_value; lookup_array; [match_type])
=CORRESP(A2;Prices!A:A;0)
Español — COINCIDIR
=COINCIDIR(lookup_value; lookup_array; [match_type])
=COINCIDIR(A2;Prices!A:A;0)
Français — EQUIV
=EQUIV(lookup_value; lookup_array; [match_type])
=EQUIV(A2;Prices!A:A;0)
Deutsch — VERGLEICH
=VERGLEICH(lookup_value; lookup_array; [match_type])
=VERGLEICH(A2;Prices!A:A;0)
Italiano — CONFRONTA
=CONFRONTA(lookup_value; lookup_array; [match_type])
=CONFRONTA(A2;Prices!A:A;0)

Common mistakes

  • match_type 0 is exact. 1 (or omitted) assumes the range is sorted ascending and can return the wrong position. -1 assumes descending order.
  • MATCH returns a number (the position), not the looked-up value. Wrap it in INDEX to get the value.
  • The lookup array should be one row or one column, not a block.

FAQ

What is MATCH in Portuguese?

CORRESP. Spanish COINCIDIR, French EQUIV, German VERGLEICH, Italian CONFRONTA.

Why do I get #N/A?

No exact match (and you used 0), or extra spaces. Try TRIM on both sides, or use XLOOKUP with an if_not_found message.

MATCH vs XMATCH?

XMATCH is the newer version (search last-to-first, built-in not-found). MATCH is the one that works in older Excel.
