What COUNTIFS does

The multi-condition version of COUNTIF. Names: CONTAR.SE.S, CONTAR.SI.CONJUNTO, NB.SI.ENS, ZÄHLENWENNS, CONTA.PIÙ.SE.

Counts cells that meet several conditions at once.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — COUNTIFS
=COUNTIFS(criteria_range1, criteria1, [criteria_range2, criteria2], …)
=COUNTIFS(B:B,"Rent",C:C,">100")
Português (PT) — CONTAR.SE.S
=CONTAR.SE.S(criteria_range1; criteria1; [criteria_range2; criteria2]; …)
=CONTAR.SE.S(B:B;"Rent";C:C;">100")
Español — CONTAR.SI.CONJUNTO
=CONTAR.SI.CONJUNTO(criteria_range1; criteria1; [criteria_range2; criteria2]; …)
=CONTAR.SI.CONJUNTO(B:B;"Rent";C:C;">100")
Français — NB.SI.ENS
=NB.SI.ENS(criteria_range1; criteria1; [criteria_range2; criteria2]; …)
=NB.SI.ENS(B:B;"Rent";C:C;">100")
Deutsch — ZÄHLENWENNS
=ZÄHLENWENNS(criteria_range1; criteria1; [criteria_range2; criteria2]; …)
=ZÄHLENWENNS(B:B;"Rent";C:C;">100")
Italiano — CONTA.PIÙ.SE
=CONTA.PIÙ.SE(criteria_range1; criteria1; [criteria_range2; criteria2]; …)
=CONTA.PIÙ.SE(B:B;"Rent";C:C;">100")

Common mistakes

  • All ranges must be the same size.
  • The same operator and concatenation rules as COUNTIF apply: ">="&F1, never a typographic ≥.
  • AND is implicit (every condition at once). For OR, add two COUNTIFS, or use SUMPRODUCT.
