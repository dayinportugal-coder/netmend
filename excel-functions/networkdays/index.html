What NETWORKDAYS does

Turnaround times, SLA clocks, visa or bank “working days”. The Portuguese name DIATRABALHOTOTAL is a mouthful, which is why people search for it.

Returns the number of working days between two dates, optionally skipping a holiday list.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — NETWORKDAYS
=NETWORKDAYS(start_date, end_date, [holidays])
=NETWORKDAYS(A2,B2)

Common mistakes

  • NETWORKDAYS counts both the start and the end date if they are working days. For a “days from today until the deadline” clock, check whether you want that inclusive behaviour, or use NETWORKDAYS.INTL / a +1 / -1 adjustment.
  • Weekends are Saturday and Sunday. For a Friday–Saturday weekend, use NETWORKDAYS.INTL.
  • Pass a holiday range (a list of dates) as the third argument, not a single typed date, if you have more than one holiday.
