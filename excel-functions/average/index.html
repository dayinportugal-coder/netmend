What AVERAGE does

Everyday average, under MÉDIA, PROMEDIO, MOYENNE, MITTELWERT, MEDIA. AVERAGE ignores blanks; a zero is still a zero and will pull the mean down.

Returns the arithmetic mean of numbers, ignoring empty cells and (usually) text.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — AVERAGE
=AVERAGE(number1, [number2], …)
=AVERAGE(C2:C100)
Português (PT) — MÉDIA
=MÉDIA(number1; [number2]; …)
=MÉDIA(C2:C100)
Español — PROMEDIO

=PROMEDIO(C2:C100)
Français — MOYENNE

Deutsch — MITTELWERT

=MEDIA(C2:C100)

Common mistakes

  • A zero and a blank are not the same. If missing data was entered as 0, AVERAGE will treat it as a real value.
  • For “average if”, use AVERAGEIF / AVERAGEIFS (not on this short list, but the translator knows them if they are in your formula’s function list… they may be left unchanged if they are not). State the condition clearly or use SUMIF/COUNTIF.
