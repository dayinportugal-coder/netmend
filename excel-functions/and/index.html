What AND does

Used inside IF. The name becomes a single letter in several languages (E, Y, ET, UND), which is easy to miss when you translate a formula by hand.

Returns TRUE only if every condition is true.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — AND
=AND(logical1, [logical2], …)
=AND(C2>0,D2<>"")
Português (PT) — E
=E(logical1; [logical2]; …)
=E(C2>0;D2<>"")
Español — Y
=Y(logical1; [logical2]; …)
=Y(C2>0;D2<>"")
Français — ET
=ET(logical1; [logical2]; …)
=ET(C2>0;D2<>"")
Deutsch — UND
=UND(logical1; [logical2]; …)
=UND(C2>0;D2<>"")
Italiano — E
=E(logical1; [logical2]; …)
=E(C2>0;D2<>"")

Common mistakes

  • AND cannot live in a SUMIF criteria on its own. For several conditions on a sum or count, use SUMIFS / COUNTIFS.
  • In Portuguese the function is just E. A missing letter looks like a broken formula, not a missing function name.

FAQ

What is AND in Portuguese?

E. Spanish Y, French ET, German UND, Italian E.

AND vs OR?

AND needs every test to be true. OR (OU / O / OU / ODER / O) needs only one.
