What LEN does

The usual partner of LEFT / RIGHT / MID, under NÚM.CARAT, LARGO, NBCAR, LÄNGE, LUNGHEZZA.

Returns the number of characters in a text string, including spaces.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — LEN
=LEN(text)
=LEN(A2)
Português (PT) — NÚM.CARAT
=NÚM.CARAT(text)
=NÚM.CARAT(A2)
Español — LARGO
=LARGO(text)
=LARGO(A2)
Français — NBCAR
=NBCAR(text)
=NBCAR(A2)
Deutsch — LÄNGE
=LÄNGE(text)
=LÄNGE(A2)
Italiano — LUNGHEZZA
=LUNGHEZZA(text)
=LUNGHEZZA(A2)

Common mistakes

  • LEN counts spaces. Use TRIM first if you want the length of the visible text.
  • A number passed to LEN is converted to text first, so formats can change the count.
