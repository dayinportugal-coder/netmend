What IFERROR does

The usual wrapper around a lookup, so a missing code shows “not found” instead of #N/A. Names: SE.ERRO, SI.ERROR, SIERREUR, WENNFEHLER, SE.ERRORE.

Returns a fallback value if the formula produces an error, otherwise the formula result.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — IFERROR
=IFERROR(value, value_if_error)
=IFERROR(VLOOKUP(A2,Prices!A:C,3,FALSE),"not found")
Português (PT) — SE.ERRO
=SE.ERRO(value; value_if_error)
=SE.ERRO(PROCV(A2;Prices!A:C;3;FALSO);"not found")
Español — SI.ERROR
=SI.ERROR(value; value_if_error)
=SI.ERROR(BUSCARV(A2;Prices!A:C;3;FALSO);"not found")
Français — SIERREUR
=SIERREUR(value; value_if_error)
=SIERREUR(RECHERCHEV(A2;Prices!A:C;3;FAUX);"not found")
Deutsch — WENNFEHLER
=WENNFEHLER(value; value_if_error)
=WENNFEHLER(SVERWEIS(A2;Prices!A:C;3;FALSCH);"not found")
Italiano — SE.ERRORE
=SE.ERRORE(value; value_if_error)
=SE.ERRORE(CERCA.VERT(A2;Prices!A:C;3;FALSO);"not found")

Common mistakes

  • IFERROR catches every error, including #DIV/0! and #VALUE! you might want to see. If you only want to hide #N/A, use IFNA where available.
  • Do not wrap an entire model in IFERROR — you will hide real mistakes. Use it on the lookup or the external input, not on every total.

FAQ

What is IFERROR in Portuguese?

SE.ERRO. Spanish SI.ERROR, French SIERREUR, German WENNFEHLER, Italian SE.ERRORE.

IFERROR vs IFNA?

IFNA only catches #N/A, which is what a failed lookup returns. Prefer it when your Excel has it.
