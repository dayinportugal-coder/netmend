What EOMONTH does

Month-end close, invoice due dates, D7-style “last day of the month” rules. Names: FIMMÊS, FIN.MES, FIN.MOIS, MONATSENDE, FINE.MESE.

Returns the last day of a month, a given number of months before or after a start date.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — EOMONTH
=EOMONTH(start_date, months)
=EOMONTH(A2,0)
Português (PT) — FIMMÊS
=FIMMÊS(start_date; months)
=FIMMÊS(A2;0)
Español — FIN.MES
=FIN.MES(start_date; months)
=FIN.MES(A2;0)
Français — FIN.MOIS
=FIN.MOIS(start_date; months)
=FIN.MOIS(A2;0)
Deutsch — MONATSENDE
=MONATSENDE(start_date; months)
=MONATSENDE(A2;0)
Italiano — FINE.MESE
=FINE.MESE(start_date; months)
=FINE.MESE(A2;0)

Common mistakes

  • EOMONTH(A2,0) is the last day of the month of A2. EOMONTH(A2,1) is the last day of the following month.
  • The result is a date, not text. Format the cell as a date, or wrap TEXT if you need a label.
