What SUMPRODUCT does

Before SUMIFS, this was how you did “total where category = Rent”. It is still the way to do weighted totals and some OR conditions. The Italian name MATR.SOMMA.PRODOTTO is a frequent search.

Multiplies ranges together and adds the results. Also a way to do conditional sums in older Excel.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — SUMPRODUCT
=SUMPRODUCT(array1, [array2], …)
=SUMPRODUCT((B2:B100="Rent")*(C2:C100))
Português (PT) — SOMARPRODUTO
=SOMARPRODUTO(array1; [array2]; …)
=SOMARPRODUTO((B2:B100="Rent")*(C2:C100))
Español — SUMAPRODUCTO
=SUMAPRODUCTO(array1; [array2]; …)
=SUMAPRODUCTO((B2:B100="Rent")*(C2:C100))
Français — SOMMEPROD
=SOMMEPROD(array1; [array2]; …)
=SOMMEPROD((B2:B100="Rent")*(C2:C100))
Deutsch — SUMMENPRODUKT
=SUMMENPRODUKT(array1; [array2]; …)
=SUMMENPRODUKT((B2:B100="Rent")*(C2:C100))
Italiano — MATR.SOMMA.PRODOTTO
=MATR.SOMMA.PRODOTTO(array1; [array2]; …)
=MATR.SOMMA.PRODOTTO((B2:B100="Rent")*(C2:C100))

Common mistakes

  • A common AI or copy-paste mistake is to add the arrays (+) instead of multiplying them (*). That quietly gives the wrong total.
  • Do not use whole-column references (B:B) in SUMPRODUCT — it is slow. Stick to the used rows.
  • The (condition)*(numbers) pattern coerces TRUE/FALSE to 1/0. That is intentional.

FAQ

What is SUMPRODUCT in Portuguese?

SOMARPRODUTO. Spanish SUMAPRODUCTO, French SOMMEPROD, German SUMMENPRODUKT, Italian MATR.SOMMA.PRODOTTO.

SUMPRODUCT vs SUMIFS?

Use SUMIFS when every condition is a simple “equals / greater than”. Use SUMPRODUCT for weighted totals, OR patterns, or older files.
