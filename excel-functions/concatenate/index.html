What CONCATENATE does

Still widely taught, even though TEXTJOIN and the &amp; operator are usually better. Names: CONCATENAR, CONCATENER, VERKETTEN, CONCATENA.

Joins several pieces of text into one string.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — CONCATENATE
=CONCATENATE(text1, [text2], …)
=CONCATENATE(A2," ",B2)
Português (PT) — CONCATENAR
=CONCATENAR(text1; [text2]; …)
=CONCATENAR(A2;" ";B2)
Español — CONCATENAR
=CONCATENAR(text1; [text2]; …)
=CONCATENAR(A2;" ";B2)
Français — CONCATENER
=CONCATENER(text1; [text2]; …)
=CONCATENER(A2;" ";B2)
Deutsch — VERKETTEN
=VERKETTEN(text1; [text2]; …)
=VERKETTEN(A2;" ";B2)
Italiano — CONCATENA
=CONCATENA(text1; [text2]; …)
=CONCATENA(A2;" ";B2)

Common mistakes

  • CONCATENATE cannot use a delimiter for a whole range. For “join A2:A10 with commas, skip blanks”, use TEXTJOIN.
  • Microsoft recommends CONCAT or TEXTJOIN in current Excel. CONCATENATE still works, which is why old workbooks keep it.

FAQ

What is CONCATENATE in Portuguese?

CONCATENAR (same in Spanish). French CONCATENER, German VERKETTEN, Italian CONCATENA.

Should I still use it?

For two or three pieces, =A2&" "&B2 is enough. For a list, use TEXTJOIN.
