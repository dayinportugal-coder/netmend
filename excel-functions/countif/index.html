What COUNTIF does

Simple, and easy to get a quiet 0. The name becomes CONTAR.SE, CONTAR.SI, NB.SI, ZÄHLENWENN, CONTA.SE.

Counts the cells in a range that meet one condition.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — COUNTIF
=COUNTIF(range, criteria)
=COUNTIF(B:B,"Rent")
Português (PT) — CONTAR.SE
=CONTAR.SE(range; criteria)
=CONTAR.SE(B:B;"Rent")
Español — CONTAR.SI
=CONTAR.SI(range; criteria)
=CONTAR.SI(B:B;"Rent")
Français — NB.SI
=NB.SI(range; criteria)
=NB.SI(B:B;"Rent")
Deutsch — ZÄHLENWENN

=ZÄHLENWENN(B:B;"Rent")
Italiano — CONTA.SE
=CONTA.SE(range; criteria)
=CONTA.SE(B:B;"Rent")

Common mistakes

  • The ≥ symbol is not an operator. =COUNTIF(E2:E100,"≥500") looks for the literal text “≥500”. Always type >=.
  • A cell in the criteria needs concatenation: ">="&F1, not ">=F1".
  • Numbers stored as text (left-aligned after a CSV import) do not match a numeric criterion. Use VALUE or Text to Columns first.
  • For dates, use DATE in the criteria: ">="&DATE(2026,7,1). A typed date string depends on the regional settings and can match nothing.

FAQ

What is COUNTIF in Portuguese?

CONTAR.SE. Spanish CONTAR.SI, French NB.SI, German ZÄHLENWENN, Italian CONTA.SE.

Why do I get 0?

A literal ≥, a criterion written as ">=F1", numbers stored as text, or a date string in the wrong locale are the four usual causes.

How do I count non-empty cells with a condition?

COUNTIF with "<>" counts non-empty cells. For several conditions, use COUNTIFS.
