What IF does

The first function most people meet — and the one whose name changes to SE, SI, WENN, which is easy to miss in a translated workbook.

Returns one value if a condition is true, and another if it is false.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — IF
=IF(logical_test, value_if_true, value_if_false)
=IF(C2>=100,"ok","low")
Português (PT) — SE
=SE(logical_test; value_if_true; value_if_false)
=SE(C2>=100;"ok";"low")
Español — SI
=SI(logical_test; value_if_true; value_if_false)
=SI(C2>=100;"ok";"low")
Français — SI
=SI(logical_test; value_if_true; value_if_false)
=SI(C2>=100;"ok";"low")
Deutsch — WENN
=WENN(logical_test; value_if_true; value_if_false)
=WENN(C2>=100;"ok";"low")
Italiano — SE
=SE(logical_test; value_if_true; value_if_false)
=SE(C2>=100;"ok";"low")

Common mistakes

  • Nested IFs become unreadable after three levels. Prefer IFS, or a lookup table with XLOOKUP / VLOOKUP.
  • To test several conditions together, wrap them in AND / OR (E / OU, Y / O, ET / OU, UND / ODER).
  • European Excel uses a semicolon between arguments: =SE(C2>=100;"ok";"low").

FAQ

What is IF in Portuguese?

SE. Spanish SI, French SI, German WENN, Italian SE.

IF vs IFS?

IFS checks several conditions in order and stops at the first true one. Use it instead of a ladder of nested IFs.
