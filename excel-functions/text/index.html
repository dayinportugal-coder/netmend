What TEXT does

Useful, and dangerous across languages: the format codes themselves are localised (yyyy vs aaaa vs jjjj).

Formats a number or a date as text, using a format code.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — TEXT
=TEXT(value, format_text)
=TEXT(C2,"0.00")
Português (PT) — TEXTO
=TEXTO(value; format_text)
=TEXTO(C2;"0.00")
Español — TEXTO
=TEXTO(value; format_text)
=TEXTO(C2;"0.00")
Français — TEXTE
=TEXTE(value; format_text)
=TEXTE(C2;"0.00")
Deutsch — TEXT
=TEXT(value; format_text)
=TEXT(C2;"0.00")
Italiano — TESTO
=TESTO(value; format_text)
=TESTO(C2;"0.00")

Common mistakes

  • English date codes use yyyy-mm-dd. Portuguese and Spanish often use aaaa-mm-dd, French aaaa-mm-jj, German jjjj-mm-tt, Italian aaaa-mm-gg. A copied format string is a frequent cause of a date turning into a 5-digit serial.
  • The result is text, not a number. You cannot SUM a column of TEXT() results without VALUE.

FAQ

What is TEXT in Portuguese?

TEXTO (same in Spanish). French TEXTE, German TEXT, Italian TESTO.

Why did my date become ##### or a serial?

The format code is in the wrong language. Use aaaa for Portuguese years, jjjj for German, and so on.
