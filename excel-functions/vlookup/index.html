What VLOOKUP does

It is still the lookup most tutorials teach, and the name everyone searches: PROCV, BUSCARV, RECHERCHEV, SVERWEIS, CERCA.VERT.

Looks up a value in the first column of a range and returns a value from a column to its right.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — VLOOKUP
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
=VLOOKUP(A2,Prices!A:C,3,FALSE)
Português (PT) — PROCV
=PROCV(lookup_value; table_array; col_index_num; [range_lookup])
=PROCV(A2;Prices!A:C;3;FALSO)
Español — BUSCARV
=BUSCARV(lookup_value; table_array; col_index_num; [range_lookup])
=BUSCARV(A2;Prices!A:C;3;FALSO)
Français — RECHERCHEV
=RECHERCHEV(lookup_value; table_array; col_index_num; [range_lookup])
=RECHERCHEV(A2;Prices!A:C;3;FAUX)
Deutsch — SVERWEIS
=SVERWEIS(lookup_value; table_array; col_index_num; [range_lookup])
=SVERWEIS(A2;Prices!A:C;3;FALSCH)
Italiano — CERCA.VERT
=CERCA.VERT(lookup_value; table_array; col_index_num; [range_lookup])
=CERCA.VERT(A2;Prices!A:C;3;FALSO)

Common mistakes

  • The fourth argument defaults to approximate match if you omit it. For an exact product code always pass FALSE (FALSO / FAUX / FALSCH / FALSO).
  • VLOOKUP can only look to the right of the first column. If the return column is to the left, use INDEX/MATCH or XLOOKUP.
  • Inserting a column inside the table silently shifts col_index_num. INDEX/MATCH and XLOOKUP do not have that problem.
  • Copied from an English tutorial into Portuguese Excel, the formula fails because of both the name and the comma separators.

FAQ

What is VLOOKUP in Portuguese?

PROCV, in both Portugal and Brazil. Spanish BUSCARV, French RECHERCHEV, German SVERWEIS, Italian CERCA.VERT.

Why do I get the wrong row?

You probably omitted FALSE, so Excel is doing an approximate match on an unsorted first column.

VLOOKUP vs XLOOKUP?

XLOOKUP can look left or right, has a built-in “not found” value, and does not break when you insert columns. Use it if your Excel has it; keep VLOOKUP when you need to share with older Excel.
