What FILTER does

The modern way to make a live subset of a table. Names: FILTRAR, FILTRE, FILTER, FILTRO. Needs a current Excel (Microsoft 365 / 2021).

Returns the rows (or columns) of a range that meet a condition, as a dynamic spill array.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — FILTER
=FILTER(array, include, [if_empty])
=FILTER(A2:C100,C2:C100>0)
Português (PT) — FILTRAR
=FILTRAR(array; include; [if_empty])
=FILTRAR(A2:C100;C2:C100>0)
Español — FILTRAR
=FILTRAR(array; include; [if_empty])
=FILTRAR(A2:C100;C2:C100>0)
Français — FILTRE
=FILTRE(array; include; [if_empty])
=FILTRE(A2:C100;C2:C100>0)
Deutsch — FILTER
=FILTER(array; include; [if_empty])
=FILTER(A2:C100;C2:C100>0)
Italiano — FILTRO
=FILTRO(array; include; [if_empty])
=FILTRO(A2:C100;C2:C100>0)

Common mistakes

  • The include argument must have the same height (or width) as the array.
  • If nothing matches and you omit if_empty, you get #CALC!. Always pass a friendly message.
  • Not in Excel 2019 or earlier. Use AutoFilter, or INDEX/MATCH, as a fallback.

FAQ

What is FILTER in Portuguese?

FILTRAR (same in Spanish). French FILTRE, German FILTER, Italian FILTRO.

Why #CALC!?

The filter came back empty. Set the third argument, for example "no rows".
