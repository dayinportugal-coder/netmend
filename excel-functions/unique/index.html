What UNIQUE does

Build a category list for a dropdown or a summary. Portuguese Excel in Portugal uses EXCLUSIVOS; Brazil may differ, as our translator page notes.

Returns a list of unique values from a range, as a dynamic spill array.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — UNIQUE
=UNIQUE(array, [by_col], [exactly_once])
=UNIQUE(B2:B100)
Português (PT) — EXCLUSIVOS
=EXCLUSIVOS(array; [by_col]; [exactly_once])
=EXCLUSIVOS(B2:B100)
Español — UNICOS
=UNICOS(array; [by_col]; [exactly_once])
=UNICOS(B2:B100)
Français — UNIQUE
=UNIQUE(array; [by_col]; [exactly_once])
=UNIQUE(B2:B100)
Deutsch — EINDEUTIG
=EINDEUTIG(array; [by_col]; [exactly_once])
=EINDEUTIG(B2:B100)
Italiano — UNICI
=UNICI(array; [by_col]; [exactly_once])
=UNICI(B2:B100)

Common mistakes

  • UNIQUE is case-insensitive for text. It does not trim spaces — TRIM the column first or you will see “Rent” and “Rent ” as two values.
  • exactly_once TRUE returns values that appear only once (the opposite of “a distinct list”).
  • Brazil may use a different name than Portugal. If a name is left unchanged, email us and we will fix the table.

FAQ

What is UNIQUE in Portuguese (Portugal)?

EXCLUSIVOS. Spanish UNICOS, French UNIQUE, German EINDEUTIG, Italian UNICI. Brazil can differ.

Why are two ‘same’ values both listed?

A trailing space or a non-breaking space. TRIM (and SUBSTITUTE of CHAR(160)) first.
