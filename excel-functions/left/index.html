What LEFT does

Everyday text chopping, under ESQUERDA, IZQUIERDA, GAUCHE, LINKS, SINISTRA.

Returns the first characters of a text string.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — LEFT
=LEFT(text, [num_chars])
=LEFT(A2,3)
Português (PT) — ESQUERDA
=ESQUERDA(text; [num_chars])
=ESQUERDA(A2;3)
Español — IZQUIERDA
=IZQUIERDA(text; [num_chars])
=IZQUIERDA(A2;3)
Français — GAUCHE
=GAUCHE(text; [num_chars])
=GAUCHE(A2;3)
Deutsch — LINKS
=LINKS(text; [num_chars])
=LINKS(A2;3)
Italiano — SINISTRA
=SINISTRA(text; [num_chars])
=SINISTRA(A2;3)

Common mistakes

  • LEFT counts characters, not words. For a first name, look for the first space with FIND / PROCURAR and then LEFT.
  • Numbers passed to LEFT become text. Wrap VALUE if you need a number again.
