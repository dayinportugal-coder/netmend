What RIGHT does

Useful for the last four digits of a card, an IBAN suffix or a year at the end of a code. Names: DIREITA, DERECHA, DROITE, RECHTS, DESTRA.

Returns the last characters of a text string.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — RIGHT
=RIGHT(text, [num_chars])
=RIGHT(A2,4)
Português (PT) — DIREITA
=DIREITA(text; [num_chars])
=DIREITA(A2;4)
Español — DERECHA
=DERECHA(text; [num_chars])
=DERECHA(A2;4)
Français — DROITE
=DROITE(text; [num_chars])
=DROITE(A2;4)
Deutsch — RECHTS
=RECHTS(text; [num_chars])
=RECHTS(A2;4)
Italiano — DESTRA
=DESTRA(text; [num_chars])
=DESTRA(A2;4)

Common mistakes

  • Like LEFT, the result is text. Use VALUE for a numeric year.
  • Combined with LEN, you can drop a prefix: =RIGHT(A2,LEN(A2)-3).
