What MID does

The start position is 1-based. Names: SEG.TEXTO, EXTRAE, STXT, TEIL, STRINGA.ESTRAI — some of the most surprising translations on the list.

Returns characters from the middle of a text string, given a start position and a length.

Syntax and a worked example in 6 languages

English Excel uses commas between arguments and a dot decimal. Most European Excel versions use semicolons and a decimal comma. TRUE / FALSE also change name. The translator below applies all three.

English — MID
=MID(text, start_num, num_chars)
=MID(A2,2,5)
Português (PT) — SEG.TEXTO
=SEG.TEXTO(text; start_num; num_chars)
=SEG.TEXTO(A2;2;5)
Español — EXTRAE
=EXTRAE(text; start_num; num_chars)
=EXTRAE(A2;2;5)
Français — STXT
=STXT(text; start_num; num_chars)
=STXT(A2;2;5)
Deutsch — TEIL
=TEIL(text; start_num; num_chars)
=TEIL(A2;2;5)
Italiano — STRINGA.ESTRAI
=STRINGA.ESTRAI(text; start_num; num_chars)
=STRINGA.ESTRAI(A2;2;5)

Common mistakes

  • start_num is 1-based (the first character is 1, not 0).
  • French STXT and German TEIL are easy to miss when you are reading a formula out loud.
