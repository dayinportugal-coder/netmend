O que faz

A maior parte dos conselhos de “porque é que isto falhou?” é vaga. Esta ferramenta tem um trabalho mais estreito: olhar para o texto que publicou de facto, assinalar os problemas habituais e oferecer uma reescrita que põe o ponto primeiro.

1. Verificações locais, de imediato

Gancho, tamanho, ligações externas, hashtags, formatação, chamada à ação, menções e hora correm no browser. Sem chave de API, sem conta, sem teto diário nesta parte.

2. Um diagnóstico e uma reescrita

Com a sua chave Gemini, obtém um diagnóstico curto e honesto e 3 versões reescritas para editar. Isto não é uma promessa de impressões. Não publica no X.

3. Privado por desenho

Esta página é estática. A publicação e a chave da API ficam no browser e vão só para a API Gemini da Google, com a chave que fornece, e só quando pede uma reescrita. A Netmend nunca os vê. Não há servidor.

Verificar uma publicação

As verificações locais são grátis e sem limite. O diagnóstico e a reescrita com IA precisam de uma chave grátis da API Gemini, da Google, e estão limitados a 3 por dia neste browser. Não emitimos chaves e não conseguimos ver a sua.

1. Acrescente a chave da API Gemini (só para a reescrita)

  1. Abra aistudio.google.com e inicie sessão com uma conta Google.
  2. Abra a página de chaves de API (Get API key) e crie uma chave. A chave Gemini grátis chega para esta ferramenta.
  3. Cole-a abaixo e clique em Guardar chave. Fica só no localStorage deste browser. Não é enviada para a Netmend, porque este sítio não tem servidor para onde a enviar. Se já guardou uma chave no X Post Writer, ela é reutilizada.

Num computador partilhado, clique em Remover chave quando terminar. Quem tiver acesso a este browser pode usar uma chave guardada.

Perguntas frequentes

Isto é o algoritmo oficial do X?

Não. Ninguém fora do X conhece os pesos exatos da ordenação, e eles mudam. Esta ferramenta é uma lista de problemas habituais no texto (um gancho fraco, uma ligação na publicação principal, uma pilha de hashtags, isco de interação, e por aí fora), mais uma reescrita opcional. Não vê as estatísticas, a audiência nem o média da publicação, e não prevê impressões.

Preciso de uma chave da API Gemini?

Não para as verificações locais. Essas correm no browser, sem chave e sem teto diário. Só precisa de uma chave se quiser o diagnóstico com IA e as 3 reescritas. A Google oferece uma chave grátis da API Gemini através do Google AI Studio. Os limites e a disponibilidade são da Google, não nossos, e podem mudar. Não revendemos chaves e não temos uma conta Google paga por trás desta página.

Onde fica a chave? Veem as publicações?

A chave fica no localStorage do browser. A publicação é enviada só para a API Gemini da Google, a partir do browser, com essa chave, e só quando clica no botão de reescrita. A Netmend não recebe a chave, a publicação nem a reescrita. Não há servidor Netmend para esta ferramenta. Num computador partilhado, use Remover chave quando terminar. Se já guardou uma chave no X Post Writer neste mesmo browser, ela é reutilizada.

O que conta para o limite diário?

Um clique em “Diagnosticar e reescrever com o Gemini”. A versão grátis permite 3 por dia neste browser. As verificações locais não contam. A contagem fica no localStorage, por isso é por browser, não por pessoa. Limpar os dados do sítio repõe-na, e não tentamos impedir isso, mas o uso justo é 3 reescritas com IA por dia.

Publica no X por mim?

Não. Verifica o texto e, se pedir, escreve uma reescrita. Copia a versão que lhe agrada e publica-a.

Posso colar uma publicação noutro idioma?

Sim. As verificações locais de tamanho, ligações, hashtags, menções e formatação funcionam em qualquer idioma. Algumas expressões de gancho e de chamada à ação são específicas do inglês, por isso esses pontos podem ser menos precisos. Se pedir uma reescrita, o modelo está instruído para escrever no mesmo idioma da publicação original.

O que as verificações locais olham

São os pontos que o browser corre sem chave. São estruturas e padrões, não uma fórmula de ordenação.

GanchoA primeira linha tem de se aguentar sozinha. Enchimento, uma ligação nua, uma hashtag ou um @ no início são assinalados.
TamanhoPublicações muito curtas deixam pouco a que responder. Publicações com mais de 280 caracteres precisam de uma razão para serem tão longas.
Ligações externasUma ligação na publicação principal viaja muitas vezes pior do que o mesmo texto com a ligação numa resposta.
HashtagsZero ou uma costuma chegar. Uma pilha de etiquetas é tratada como problema.
FormataçãoParedes de texto, tudo em maiúsculas, montes de emoji, pontuação repetida e travessões longos.
Chamada“Gostem se concordam” e iscos parecidos são assinalados. Uma pergunta concreta não é.
MençõesUma lista longa de etiquetas, ou uma publicação que começa com @ e pode ser tratada como resposta.
HoraOpcional. Uma janela calma no fuso que indicar é assinalada. Isto não é uma calculadora da melhor hora.
