Try Xero’s official imports first

Xero Central documents two relevant articles: Import a bank statement in CSV format and Import a PDF bank statement. If your organisation offers the PDF import for that account and it accepts your file, use it — there is no reason to convert a statement Xero already reads. When the PDF import is not offered, or it rejects the layout, prepare a CSV and import that instead (Accounting → Bank accounts → the account → Import a statement, then map the columns and review the lines).

A live bank feed is still the better everyday path. Several banks in our bank guides already offer an official CSV or XLS for recent activity (for example Starling feed exports, bunq CSV, ABN AMRO XLS for 18 months, Commerzbank Umsatz CSV). Use those when they cover the dates. Convert a PDF when they do not.

The CSV Xero expects

On the official CSV import you map columns on screen. In practice the file that goes through cleanly has:

  • A Date column, in one format only (for example DD/MM/YYYY, MM/DD/YYYY or YYYY-MM-DD — pick the one you will also select in Xero).
  • An Amount column, with money in as a positive number and money out as a negative number, and with no currency symbols or thousands separators that Xero will misread (1,234.56 in a European locale is a trap).
  • A Description (and, if you have them and the mapper offers them, payee or reference). Extra columns are fine if you can leave them unmapped.

Treat the mapping screen and Xero’s current article as the authority if a heading has changed. The usual failures are mixed date formats, a European decimal comma in a file Xero is reading as US, or a “balance” column imported as if it were an amount — that last mistake posts the running total as a transaction.

Convert the PDF, then check it

The tool below runs in your browser. Choose a European or UK/US number format to match the statement. Then:

  1. Delete header and footer rows. Keep only actual movements.
  2. Build a single signed Amount column if the PDF had money in and money out separately (in minus out).
  3. Prove the file: opening balance + sum of amounts = closing balance on the PDF. If that identity fails, do not import.
  4. Import in Xero, map Date and Amount (and Description), review the statement lines, and only then complete the import. Do not import a period that is already on the bank feed.

FAQ

Can Xero import my PDF statement directly?

Sometimes. Xero Central has an official article “Import a PDF bank statement”. Try that first. If it is not available or the file is rejected, convert the PDF to a CSV and use the official CSV import.

Should amounts be positive or negative?

For the usual single-amount CSV, money in is positive and money out is negative. Do not also import a running-balance column as an amount.

Why are the dates a day off or in the wrong month?

The statement is probably day-first and the import was told it is month-first, or the other way around. Pick one format for the whole file and say it on the mapping screen.
