Text PDF versus scanned PDF

A digital invoice from a supplier’s billing system usually has a text layer. You can highlight “£120.00”, search for the invoice number, and a converter can read the table. A scanned or photographed invoice is an image placed on a PDF page. It may look sharp, and it may even be called a PDF, but there are no characters to extract — only pixels. The free tool on this page, like most local PDF-table tools, will return a blank or a jumble of random letters if there is no text layer.

A quick test: open the file, try to highlight a total, and copy it into a notes app. If you get the number, try the converter below (start with “Every text row”). If you get nothing, or a single letter, stop — running the tool again will not invent the missing text.

What to do with a scan

  • Ask for a digital copy. Many suppliers can resend the original PDF from their invoicing software. That is the cheapest fix, and it is the official document.
  • Type the rows. For a handful of invoices this is faster than setting up OCR, and you see each total as you go. Use a simple sheet: invoice number, date, supplier, description, net, tax, gross. Tick each gross against the paper or the scan before you add the next one.
  • OCR, if you accept the error rate. Adobe Acrobat, Apple’s PDF tools, Google Drive, and similar software can try to recognise the characters. They make quiet mistakes: a 3 that becomes an 8, a decimal comma that disappears, a line that is skipped. If you use OCR, you still have to tick every invoice total against the scan. OCR is a typing aid, not a source of truth.
  • Done for you. If you have a packed folder of scans, mixed languages, or a layout that has to match QuickBooks or Xero, we key the lines and check each document total. That is the paid option below — it is not a magic scan button on this page.

The tool is still here because mixed packs are common: three digital invoices and two scans. Run the digital files through it, type the scans, and keep one working sheet. Then, if you need to import into QuickBooks or Xero, copy the rows into that product’s official template and map the columns there.

How to tick a pack so mistakes do not slip through

  1. Number the source files and put that name on each spreadsheet row.
  2. For every invoice, compare the printed gross (and the tax total, if it is shown) with the sum of the lines you captured. If a document has three lines of 40, 40 and 40 and a gross of 132, you are missing tax or you have the wrong currency.
  3. Add a pack total — the sum of every gross — and compare it with a control you already trust, such as a purchase ledger or a card-statement total for the same suppliers and dates. A pack that only “looks complete” is how one invoice gets dropped.

FAQ

Why is the preview empty?

The file is probably a scan or a photograph. This tool only reads a text layer. Try highlighting a total in the PDF; if you cannot copy it, the tool cannot read it either.

Can you “enable OCR” in the free tool?

No. Building a reliable, private OCR engine into this page would still leave you ticking every total, and it would fail quietly on poor scans. We would rather say so than ship a button that guesses.

Is a scanned PDF still a valid invoice?

Often yes, as a picture of the document — but your tax rules are not this page’s job. For the spreadsheet, treat the scan as evidence and type or key the numbers, then tick them.
