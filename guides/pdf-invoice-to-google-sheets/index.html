Extract first, then import

The converter below runs in your browser and never uploads the invoice. It is useful when the PDF is a digital file with a line-item table. It is not useful on a scan or a photograph — see scanned invoices. Use “Every text row” if the first preview drops a wrapped description. Download the CSV to your computer, then in Google Sheets: File → Import → Upload, and import as a new sheet or a new tab.

On the import dialog, be deliberate:

  • Choose the separator that matches the file (comma for a UK/US export from our tool, semicolon if you picked the European Excel option).
  • Convert text to numbers, dates and formulas only if you have already looked at a sample row. Sheets is helpful, and that is the problem: 03/04/2026 will become 3 April or 4 March depending on the locale of the spreadsheet, and 1,25 may become a thousand-and-twenty-five or a quarter.
  • If in doubt, import the columns as plain text, then use a helper column with DATE, VALUE or SUBSTITUTE to build real dates and numbers you can check. Our formula translator has the equivalent function names if your Sheets locale is not English (Google Sheets often still accepts English names, but it uses your locale’s separators).

A working sheet that you can tick

Once the raw extract is in, build a clean tab rather than editing the import in place:

  1. One row per line item, with the invoice number repeated, plus a header row you type yourself (invoice number, date, supplier, description, quantity, unit price, net, tax, gross).
  2. A second tab that lists one row per invoice: invoice number, the printed total from the PDF, and a SUMIF (or SOMA.SE in Portuguese Excel) of the line grosses. Every row on that tab should match. If it does not, stop and fix the extract before you share the file.
  3. Keep a column with the original PDF file name, so a mismatch can be opened and checked.

If the destination is QuickBooks or Xero, this Sheet is a working file, not the import file. Copy the checked rows into that product’s official template — see the QuickBooks and Xero guides. Sheets is a fine place to clean the data; it is not a substitute for their column names.

FAQ

Can I open a PDF directly in Google Sheets?

No usefully. Sheets opens CSVs and Excel files. Convert the PDF on your computer first, then import the CSV. A Drive OCR step on a scan is a separate, error-prone process — tick every total if you use it.

Why did 03/04 become the wrong day?

The spreadsheet locale decided whether that is 3 April or 4 March. Import dates as text first, or set the locale to match the invoice, then confirm the first few rows against the PDF.

Should I pick comma or semicolon in the tool?

Comma for typical Google Sheets and UK/US Excel (dot decimals). Semicolon for most mainland-European Excel. You can change this on the converter before you download, and again on the Sheets import dialog.
