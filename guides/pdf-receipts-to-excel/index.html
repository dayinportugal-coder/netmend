What a useful receipt sheet looks like

For bookkeeping, one row per receipt is almost always better than one row per word the PDF happened to contain. A practical set of columns is:

  • Date — the receipt date, in one format only (DD/MM/YYYY in the UK and Europe, MM/DD/YYYY in the US).
  • Supplier — the name on the receipt, not the payment-processor name if you can help it (a “SumUp” or “Stripe” line is harder to review later).
  • Description — what it was for, in a few words.
  • Net, VAT or sales tax, and gross — as printed. If the receipt has no tax break-down, leave net and VAT blank and keep the gross, rather than inventing a split.
  • Currency and payment method if you have mixed cards or a foreign trip.
  • Source file — the PDF name, so you can find the original in a month’s time.

If you later import this into QuickBooks or Xero, you still need their bill or expense template. The sheet above is the working file; their sample CSV is the import file. Do not import receipts as bank transactions if the same card spend will also arrive on the bank feed — you will double-count.

FAQ

Will this read a photo of a till receipt?

No. The tool reads the text layer of a digital PDF. A photograph is an image. Type that row, use receipt capture in your accounting software, or send the pack to us.

Should each item on the receipt be its own row?

Only if you need that detail (for example stock or a mixed VAT rate). For most small-business books, one row per receipt with the printed gross is enough and easier to tick.

Can I import this sheet straight into Xero or QuickBooks?

Not as-is. Copy the rows into that product’s expense, bill or receipt template. And do not also import the same spend from the bank feed without matching the two.
