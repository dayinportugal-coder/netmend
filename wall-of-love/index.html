FAQ

Does the wall update itself?

No. It is plain HTML that you own, so it never breaks and never needs a subscription. To add a review, paste it here again and replace the code (1 minute).

Will it slow down my site?

No. It is a few lines of CSS and HTML, no JavaScript, no external files.

Can I use it on Shopify / WordPress / Wix?

Yes: add a "Custom HTML" (WordPress), "Custom Liquid" (Shopify) or "Embed code" (Wix) block and paste the code.

Is this an alternative to Senja, Testimonial.to or Curator?

For the "show reviews on my site" part, yes, for free. Those tools also collect video testimonials and sync automatically, which this free tool doesn't do.
