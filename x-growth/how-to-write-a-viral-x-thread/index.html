Como escrever um thread viral no X

A maior parte dos threads não se torna viral, incluindo os escritos com cuidado. O que pode controlar é se um thread é fácil de abrir, fácil de acabar e fácil de partilhar: uma primeira publicação que se aguenta sozinha, uma ideia por publicação, e um fecho que não caia num pitch. Isso é o ofício. A distribuição fica depois com o público e com a plataforma.

«Viral», nas pesquisas, quer em regra dizer «quero que isto viaje mais longe do que os seguidores que tenho». Não há um fornecedor honesto, incluindo a Netmend, que possa prometer isso. Há uma forma de escrever que retira as razões habituais de um thread morrer: um gancho vago, um divagar, um isco que muda de assunto, ou uma primeira publicação que não faz sentido sem o resto.

Esta página é uma estrutura, com threads de exemplo originais que pode adaptar. Use só factos que consiga defender. Não invente números para tornar um gancho mais alto.

Uma estrutura fácil de partilhar

Publicação 1Um pensamento completo. Um facto concreto, uma afirmação nítida que consiga defender, ou uma pergunta que nomeie uma situação real. O leitor deve saber porque abriria o resto.
Publicações 2 a NUma ideia por publicação. Um passo, um exemplo, um contra-argumento, um limite. Curto o suficiente para se ler no telemóvel. Numere se a sequência importar.
O fechoUma conclusão, um limite do argumento, ou um passo seguinte que o leitor possa dar sem comprar nada. Se tiver um link, pode ficar aqui, uma vez, com clareza.

A primeira publicação tem de funcionar no feed por si. Se só disser «Um thread» ou «Aqui está tudo o que sei sobre X», quem ainda não confia em si continua a deslizar. Ponha a frase mais concreta primeiro.

Não estique uma ideia de 4 publicações até 18. Não esconda o ponto atrás de um pigarro longo. Não acabe em «siga para a parte 2» se a parte 2 for a resposta de facto.

Threads de exemplo (fictícios, completos)

Cada exemplo é um thread curto, escrito para esta página. Não são contas reais, nem um registo de impressões.

Thread · processo, 4 publicações · exemplo
1/ Deixámos de fazer chamadas de arranque sem agenda. O trabalho ficou melhor, não pior.

2/ Antes da chamada, os dois lados escrevem: o trabalho, o prazo, o intervalo de orçamento, e como é o «feito» num ficheiro ou numa página.

3/ Se não conseguirem escrever essas quatro linhas, não marcamos a chamada. Esse filtro poupou mais tempo do que qualquer ferramenta nova.

4/ Se já tiver as quatro linhas, uma chamada de 30 minutos passa a ser útil. Se não tiver, o e-mail chega. É o método todo.
Thread · um facto concreto, 3 publicações · exemplo
1/ O pedido de apoio a que respondemos 40 vezes em outubro não era um erro. As pessoas colavam um token de API no campo «ID do espaço de trabalho».

2/ Mudámos o nome do campo, pusemos um valor de exemplo, e passámos a rejeitar tokens com uma mensagem de erro específica. A documentação, sozinha, não tinha chegado.

3/ Se tiver um pedido que se repete, mude a interface, não só o artigo de ajuda. É a lição; não há parte 4.
Thread · uma afirmação com limites, 4 publicações · exemplo
1/ Um thread devia ser mais curto do que o entusiasmo.

2/ Se o ponto é um método de três passos, escreva três publicações e um fecho, não umas memórias de como descobriu o método.

3/ Se uma publicação é só uma piada, um pigarro, ou «como disse acima», corte-a. O leitor já teve de clicar uma vez.

4/ Conte as publicações antes de publicar. Se puder cortar duas e o argumento se mantiver, corte duas.
Thread · como fazer, 5 publicações · exemplo
1/ Se quer um thread útil de sector, escreva-o a partir de um trabalho que fez mesmo no mês passado, não a partir de «o futuro do trabalho».

2/ Comece pelo constrangimento: o tempo, o orçamento, a ferramenta a que estava preso.

3/ Conte os passos pela ordem em que os fez, incluindo o que falhou.

4/ Diga o que repetiria, e o que foi sorte ou um caso único.

5/ Pare. Um link para o texto mais longo pode ficar aqui se o tiver. O thread deve continuar a fazer sentido se ninguém clicar.
Thread · viragem curta, 3 publicações · exemplo
1/ «Vou escrever um thread viral» é uma má primeira linha, porque é sobre si, não sobre o leitor.

2/ Uma primeira linha melhor é um facto, um erro, ou um método que o leitor possa usar sem o conhecer.

3/ Se viaja ou não, isso já não está nas suas mãos. A escrita tem ainda de ser boa o suficiente para não se importar se ficar com 40 pessoas.
Só a primeira publicação · fraca e mais forte · exemplo
Fraca: «Um thread sobre como fazemos o onboarding.»

Mais forte: «Escondemos todos os botões do ecrã inicial até o utilizador acrescentar um cliente. A queda dos testes nesse passo é o que estamos a tentar mexer.»

A segunda já é uma publicação. O resto de um thread, se precisar dele, pode explicar como e porquê.
O que não fazer · exemplo
Não abra com «Não acredito que isto não se discuta mais».
Não prometa «o único guia de que alguma vez vai precisar».
Não invente uma estatística para o gancho.
Não espere pela publicação 9 para dizer o ponto.
Não acabe em «goste e siga para a parte 2» se já tiver o fim.
Fechos que não são uma venda dura · exemplo
Fechos úteis:
«É o método todo. Uso-o em reconstruções de sites.»
«Se os seus factos forem outros, isto pode não se aplicar.»
«Escrevi uma versão mais longa no site. Os passos acima aguentam-se sozinhos se ninguém clicar.»

Menos útil: «Comente “GUIA” e mando-lhe o PDF por mensagem.» Isso é uma armadilha, e as pessoas tratam-no como tal.

Estes são rascunhos originais, escritos para esta página, de um profissional fictício. Não são publicações de uma conta real, nem uma promessa de alcance, clientes ou vendas. Adapte a estrutura e substitua cada facto por um que consiga defender.

Depois do rascunho

Leia a primeira publicação sozinha. Se estiver vaga, reescreva-a antes de tocar no resto. Leia o thread em voz alta. Corte qualquer publicação que só exista para manter uma sequência. Confira cada número. Depois, se quiser alternativas, cole o índice e algumas publicações antigas no X Post Writer grátis e peça threads curtos. Ele rascunha; não sabe se um número é verdadeiro, e não pode fazer um thread viajar.

Perguntas frequentes

Há um truque para ficar viral no X?

Não há um fiável. Escrita clara, uma primeira linha concreta, e um tema de que as pessoas já gostam ajudam uma publicação a ter uma oportunidade justa. Truques (isco de interação, urgência falsa, marcar desconhecidos) custam em regra mais confiança do que compram.

Qual deve ser o comprimento de um thread?

Tão curto quanto a ideia permitir. Muitos bons têm três a seis publicações. Se precisar de doze, provavelmente tem dois threads, ou um texto de blogue com um thread curto como resumo.

Cada publicação do thread deve funcionar sozinha?

A primeira tem de funcionar. As outras podem assumir que o leitor abriu o thread, mas cada uma deve continuar a ser uma ou duas frases completas, não um «E depois…» pendurado.
