How to write an X thread

A thread is a good shape when you have a sequence: a method, a story with more than one turn, or a list that would be cramped in a single post. It is a bad shape when you have one idea and you are stretching it so it looks like a “thread”.

If you came here because you want a thread to travel widely, read the companion page on writing a so-called viral thread as well. The craft is the same. The honest limit is the same: you can make a thread easy to read, you cannot order it to spread.

Standard accounts still work in a short character budget per post; longer posts exist on paid X plans. Check the counter in your own composer. Either way, one idea per post is easier to read on a phone than a wall of text split at random.

Build it in this order

  • Write the point in one sentence. If you cannot, you are not ready to thread it.
  • List the posts as headings (five to eight at most, often fewer). Each heading is one idea.
  • Write the first post last. It has to stand alone in the feed, with a concrete hook.
  • Write the middle in order. Steps, examples, a failed attempt, a limit. Number them if the sequence matters.
  • Write a finish that is a takeaway or a next step, not a cliff-hanger for “part 2” you have not written.
  • Cut. Read it once without mercy. Any post that only says “as I mentioned” goes.

Example threads and shapes

Method thread, 5 posts · example
1/ A freelance project I will not start without a written brief any more. The brief is four lines.

2/ What already exists: files, logins, brand, earlier drafts.

3/ What “done” looks like, in deliverable files, not in a feeling.

4/ The drop-dead date, and why it is that date.

5/ Who signs off — one name. If those four lines cannot be written, we do not book a kickoff call. That is the whole method.
Story thread, 4 posts · example
1/ We had a ticket we answered 40 times in October, and it was not a bug.

2/ People were pasting an API token into the workspace ID field. The docs said not to. The docs were not being read at that moment.

3/ We relabelled the field, put an example value in the box, and rejected tokens with a specific error.

4/ Tickets dropped. The lesson I kept: if a mistake repeats, change the interface, not only the help article.
List thread, 4 posts · example
1/ Four things I put in a product page before any adjective.

2/ What it is made of, and a limit of the material (this jumper shrinks if you tumble it).

3/ When it ships, in dates I can keep, not “ASAP”.

4/ How a return works, in the same words as the official policy. The adjectives can come after those four, or not at all.
When not to thread · example
If the second post is only a punchline, you have a single post.
If you are repeating the same idea in new words, you have a single post.
If the useful part is a link, write one post and the link, not a runway of empty posts.
First post, weak vs stronger · example
Weak: “Some thoughts on briefing, a thread.”

Stronger: “I will not start a freelance project without a four-line brief any more. Here are the four lines, and what I do if they cannot be written.”
Numbering · example
Numbering helps when the order matters (a method, a timeline). It is optional when you are offering a set of examples. If you number, keep the count honest: do not write “1/17” and then run out of material at 6.
A finish · example
Useful: “That is the whole method. I use it on website projects; your trade may need different lines.”

Less useful: “Follow me for part 2, where I reveal the template.” If the template is the point, it belongs in this thread, or in a linked page.
Editing pass · example
Read only post 1. Would you open the rest?
Read only the last post. Does it close, or does it fade out?
Read the middle on a phone preview. Cut a post. If nothing breaks, leave it cut.

FAQ

Single post or thread?

If one screen can hold the idea without cramping, use a single post. Threads cost the reader a click. Spend that click only when the sequence needs it.

Can I add images to each post?

Yes, if each image earns its place (a diagram, a screenshot you are allowed to show). Decorative images on every post slow people down.

Should I pin a thread?

Pin one that still describes the work you do. A dated fight or a one-week promotion is a poor pin.
